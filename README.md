# EGCO Study Mind Maps

Interactive Thai study mind maps generated from verified post-lecture summaries.

## Courses

- EGCO604 — Research Methodology
- EGCO611 — Mathematical Modelling
- EGCO623 — Data Mining & Machine Learning
- EGCO676 — Information Security & Cryptography

## Use

Open `index.html`, choose a course, then click a branch to expand it and read details. Search, zoom, dark mode, print/PDF, and local reading progress are included.

## Updating

Regenerate the four HTML files from the latest verified lecture summaries, replace the files in this repository, test the interactions, then commit and push to `main`. GitHub Pages republishes from the repository root.

## Data note

This repository contains synthesized course study notes. It does not include Slack exports, credentials, access tokens, or raw source files.
